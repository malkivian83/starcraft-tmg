# Auditoría de estado — 3 de agosto de 2026

Esta auditoría contrasta la documentación con el código presente en el
repositorio. Se consideran implementadas únicamente las funcionalidades que
tienen cliente, API y persistencia cuando corresponde.

## Funcionalidades verificadas como implementadas

- Registro, inicio de sesión, Google, verificación de correo, recuperación de
  contraseña y reenvío de verificación.
- Página de términos y condiciones (`/terminos-y-condiciones`), enlace desde
  los footers y aceptación obligatoria durante el registro. El titular se
  identifica como `starcraft-builder.com`.
- Listas remotas privadas y públicas, selector de visibilidad, consulta en
  modo solo lectura y clonación para crear una copia editable.
- Página de inicio con las últimas listas propias, accesos por raza y las
  últimas listas públicas.
- Página de listas públicas con búsqueda, filtros por raza, escala y validez,
  y ordenación por fecha, nombre, raza, escala, validez y número de likes.
- Likes de listas públicas, uno por usuario y lista, con contador y estado del
  usuario. La migración `008_public_list_likes.sql` está aplicada en la base de
  datos revisada.
- Previsualización de cartas tácticas en modal, con ajuste responsive para
  móvil.
- Confirmación al abandonar el constructor con cambios sin guardar y botón de
  impresión en la sección de revisión.
